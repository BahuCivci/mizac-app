# Analytics & İzleme Kılavuzu

## Her Gün Bak

### 1. Vercel Analytics
→ vercel.com → mizac-app → Analytics sekmesi
- Kaç ziyaretçi, hangi sayfalar, nereden geliyorlar

### 2. Google Analytics 4
→ analytics.google.com
- Gerçek zamanlı kullanıcı sayısı
- Ülke / cihaz dağılımı
- Sayfa başına geçirilen süre
- Test tamamlanma oranı

### 3. Google Search Console
→ search.google.com/search-console
- Hangi arama kelimeleriyle bulunuyorsun
- Tıklama ve gösterim sayıları
- Indexlenmeyen sayfalar

## Ara Sıra Bak

### 4. Google AdSense
→ adsense.google.com
- Reklam tıklamaları ve gelir

### 5. Vercel Logs
→ vercel.com → mizac-app → Functions / Logs
- API hataları (ödeme, abonelik webhookları)
- Deploy durumu

## Günlük Rutin

1. GA4 real-time → kaç kişi şu an sitede
2. Search Console → dünkü tıklama/gösterim
3. Vercel Analytics → hangi sayfa en çok ziyaret aldı
4. Vercel Logs → sadece bir şey bozulduğunda
